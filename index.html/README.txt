Jigsaw Joy PWA (เวอร์ชันมีลงชื่อ + ประวัติ + สถิติ)
1. แตกไฟล์ ZIP
2. เปิด index.html เพื่อเล่น
3. หน้าหลักมี 3 เมนู: เริ่มเกม (ลงชื่อเข้าเล่น) / ประวัติการเล่นและสถิติเวลา (แยกตามขนาดช่อง) / วิธีการเล่น
4. เมื่อต่อจิ๊กซอว์สำเร็จ ระบบบันทึก ชื่อผู้เล่น ขนาดช่อง (เช่น 4×4 = 16 ช่อง) เวลา และจำนวนครั้งที่สลับ
หมายเหตุ:
- ประวัติเก็บใน localStorage ของเบราว์เซอร์/เครื่องนั้น (ล้างข้อมูลเบราว์เซอร์ = ประวัติหาย)
- การติดตั้ง PWA และ Service Worker ต้องเปิดผ่าน HTTPS หรือ localhost
